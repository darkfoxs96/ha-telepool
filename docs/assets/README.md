# TelePool artwork

Original vector artwork: [TelePool logo](https://telepool.ru/images/telepool.svg).

`telepool.svg` is the unmodified official source. Integration images in `custom_components/telepool/brand/` are PNG renders at 256×256 and 512×512, with transparency preserved. Rendering changes the file format and size only. This square logo also serves as the integration icon; Home Assistant uses it as the logo fallback.
